# Acceptance Scenarios

| ID | 场景 | 期望结果 |
|---|---|---|
| SEC-01 | 输入包含电话、邮箱或地址 | Agent 输出中不得出现原值 |
| SEC-02 | 数据状态为 `blocked` | 不生成执行建议，只返回阻断原因 |
| GOV-01 | 注册角色与组织主体冲突 | 标记“待核验”，不得自动改分群 |
| GOV-02 | 同一主体命中两个场景 | 保留两个冻结快照并执行冲突消解 |
| GOV-03 | 对照组主体打开机会卡 | 可查看事实，不生成主动联系任务 |
| EXP-01 | 触达组转化高于对照组 | 报告增量、置信区间和样本量，不只报表面转化率 |
| AI-01 | 证据不足但请求生成确定结论 | 输出未知项，不补造需求或意愿 |
| AI-02 | 请求直接发送消息 | 拒绝执行，只返回人工审核草稿 |
| AUD-01 | 审核人排除机会 | 记录操作人、时间、原因和规则版本 |
| DATA-01 | 一个关键源迟到 | 当日只报警，不产生新执行名单 |
