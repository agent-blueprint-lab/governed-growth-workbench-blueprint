# Changelog

All notable changes to this project are documented here.

## [0.1.0] - 2026-09-16

### Added

- Installable Python CLI with deterministic, rule-first evaluation.
- JSON Schema contracts and validation for profiles, rules, opportunities, and audit events.
- Synthetic profile generator, fail-closed behavior, stable control assignment, and audit output.
- Executable unit, replay, schema, and publication-safety tests.
- CI, release automation, Dependabot, issue templates, pull-request checklist, and code ownership.
- English and Chinese quick starts, governance, threat model, maintainer workflow, and roadmap.

### Security

- Added common secret, contact, private-network, and local-path publication checks.
- Standardized public examples on `SYN-*` identifiers and demo-only rule configuration.
