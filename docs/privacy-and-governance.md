# Privacy and Governance

## 数据分区

| 区域 | 示例 | 是否进入 Agent |
|---|---|---|
| 事实区 | 最近活动天数、使用次数、权益区间 | 可，使用结构化最小字段 |
| 身份展示区 | 经核验的组织名或脱敏称呼 | 仅按 UI 权限展示 |
| 敏感区 | 电话、邮箱、地址、证件、付款明细 | 否 |
| 原始内容区 | 咨询文本、文件、录音、业务材料 | 默认否，需单独授权流程 |
| 审计区 | 操作人、版本、时间、原因、结果 | 不用于营销推理 |

## Agent 输出规范

输出必须分成：

- 已知事实：来自结构化字段；
- 规则判断：引用规则版本；
- 建议动作：可被人工拒绝；
- 待核验项：数据不足或关系不明确；
- 禁止动作：当前不能执行的行为。

## 执行边界

若系统仅用于分析与人工分配，完整自动触达门禁可以后置，但以下基础约束仍要保留：权限控制、敏感字段隔离、拒绝/投诉提示、数据完整性状态、导出审计和人工确认。
